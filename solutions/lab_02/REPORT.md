слабая ссылка позволяет обращаться к объекту, но не удерживает его в памяти.

слабые ссылки используют, чтобы хранить доступ к объектам, не мешая освобождать память, когда они больше не нужны.
### Практическое задание
слабый словарь не удерживает объекты в памяти. Когда на объект больше нет сильных ссылок, Python может удалить его, и соответствующая запись исчезает из WeakValueDictionary.
### Вопросы для анализа
1. если сильных ссылок на объект больше нет. Это значит, что объект больше нигде не используется, и Python может освободить его.

3. сильная ссылка удерживает объект в памяти, а слабая — нет. Если на объект остаются только слабые ссылки, он может быть удалён.
